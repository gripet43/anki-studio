## 发现的问题

### 1. 制卡编辑器 placeholder 在 Windows 上仍写 `Cmd+Shift+C` — A8 判失败

- 现象：新建卡片弹窗的正面输入框提示为「输入正面问题或词条（选中文字按
  **Cmd+Shift+C** 可设挖空）...」，Windows 上应为 `Ctrl+Shift+C`。
- 定位：`frontend/src/i18n/translations.ts:519` 的 `editorFrontPlaceholder` 是硬编码字符串，
  没有经过 `formatShortcut()`；而同一编辑器的工具栏 tooltip 用的是
  `TowerWysiwygEditor.tsx:1108` 的 `formatShortcut('Cmd+Shift+C', envInfo.platform)`，
  设置→快捷键页也正确显示 `Ctrl + K` / `Ctrl + Z` / `Ctrl + Alt + M`。即**只有这一处
  placeholder 漏了平台适配**。后端 `bridge/deck_service.py:173` 的平台探测（`sys.platform`
  → `win`）本身是对的。
- 复现：任意场景 → 快速制卡 → 看正面输入框 placeholder。
- 截图：`13a-editor.png`、`13b-emoji-zoom.png`（放大后同句可见）；正确对照 `09-shortcuts.png`。
- 是否阻断发布：**功能不阻断，但本轮 A8 验收项判失败**。属 Windows 特有的界面提示错误，
  建议把该文案改为带参数的翻译键并过 `formatShortcut` 后再发布。

### 2. 同步状态的两个子态未能目视验证 — B3 判部分通过

- 已验证：未同步态左侧是**云朵图标（带斜杠）而非绿圆点**（`01c-topbar-zoom.png`）；
  悬停弹出快照浮窗「AnkiWeb 云端同步 / 上次同步 尚未同步 / 尚无云端同步记录 / 当前集合尚未
  与 AnkiWeb 同步，点击下方按钮可立即同步」（`15-sync-hover.png`）。
- 未验证：①「已同步时主题色云朵随所选强调色变化」；②「同步进行中变橙色脉冲点」。
- 原因：沙盒没有 AnkiWeb 凭据。点击同步后 Anki 先弹出原生的「需要账号 / AnkiWeb 账号 / 密码」
  登录框（`16d-sync-dialog.png`），同步流程根本没开始，因此进入不了这两个状态；
  快速抓拍（`16-sync-pulse.png`、`16c-sync-zoom.png`）只抓到 toast 与灰色云朵。
- 代码层核对：`SyncStatusPill.tsx:146-166` 确认有
  `bg-[var(--status-warning)] animate-ping` 的同步中脉冲点、`SyncStateIcon` 的云图标，
  即实现存在，只是本机环境触发不了。
- 是否阻断发布：**不阻断**，但这两条需要在有 AnkiWeb 账号的真机上补验，或由前端用
  状态注入的方式补一个可复现的验证路径。
- 附带观察：该登录框是模态的，会 `IsWindowEnabled(main)=0`，我第一次点同步后没关它，
  导致后续几次点击全被吞掉。排查后按 Esc 关闭即恢复。这不是产品缺陷，记给下一位验版者。
