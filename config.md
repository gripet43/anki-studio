# Anki Studio — Add-on Configuration

- `theme`: `"light"` | `"dark"` | `"oled"` (UI Theme Mode)
- `accent_color`: `"indigo"` | `"cyan"` | `"emerald"` | `"rose"` (Brand Accent Color)
- `language`: `"auto"` | `"zh-CN"` | `"en"` (`"auto"` follows your Anki client interface language)
- `custom_nickname`: Optional display name shown in the dashboard greeting (defaults to your active Anki Profile name)
- `auto_launch_modern_ui`: Automatically open Anki Studio when Anki starts (`true` / `false`)
- `toggle_shortcut`: Fail-safe shortcut to switch between Anki Studio and native Anki (`"Ctrl+Alt+M"`)
